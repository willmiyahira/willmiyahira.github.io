Atom chips allow for the generation of complex electromagnetic fields for trapping and manipulating ultracold atoms.
Typically these devices use DC currents operating using the DC Zeeman effect.
Trapping via the AC Zeeman effect, however, offers spin-specific trapping and manipulation for atom interferometry experiments.

This work progressed the development of a microwave atom chip, notably with broadband (DC-20 GHz) capability for trapping different atomic species and operation of an AC Stark lattice.
The building block of the atom chip are multiple parallel microstrip transmission lines, which can be made to be 50 Ohms for compatability with standard RF and microwave equipment.
For a given phase relationship between the currents in the chip traces, a minimum in the circularly polarized magnetic field can be generated, which creates the trap.
